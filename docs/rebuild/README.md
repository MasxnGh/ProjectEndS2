# สร้างใหม่ทั้งหมด — แผนงาน (นับ 1 ใหม่)

เชียงใหม่ เจอร์นีย์ · branch `redesign` · เริ่ม 14 พ.ย. 2569 · ครบทั้ง 7 Phase และอนุมัติแล้ว 15 พ.ย. 2569

หลักการเดียวของงานนี้คือ **บอร์ดแบรนด์ของเจ้าของ** (`docs/redesign/reference/brand-board.webp`) ซึ่งถอดเป็นกฎไว้ใน `DESIGN.md` ที่ root ของ repo หน้าตาเว็บเดิม, brief Phase 1 เดิม และ sketch 3 ทิศทางของ Phase 2 เดิม (`docs/redesign/`) ไม่ใช้เป็นฐานแล้ว เก็บไว้เป็นประวัติเท่านั้น

## "ใหม่ทั้งหมด" ครอบคลุมอะไร

| สร้างใหม่ ไม่อิงของเดิม | ใช้ของเดิมต่อ |
|---|---|
| หน้าตาทุกหน้า: layout, component, สี, ตัวอักษร, ไอคอน, motion | ข้อมูลสถานที่ 204 แห่ง คู่มือ 3 เรื่อง และภาพถ่ายที่มีเครดิต |
| โลโก้: ใช้เครื่องหมายภูเขากับดาวสี่แฉกจากบอร์ด | การคำนวณของตัววางแผน (เวลาเดินทาง งบ ความเป็นไปได้) |
| โครงหน้าและลำดับเนื้อหาของทุกหน้า | API, ระบบเข้าสู่ระบบ, ฐานข้อมูล, URL ทุกเส้น |

ข้อมูลกับการคำนวณใช้ต่อ เพราะเป็นเนื้อของโปรดักต์ ไม่ใช่หน้าตา ถ้าต้องการให้เขียนส่วนนั้นใหม่ด้วย บอกได้ที่จุดหยุดของ Phase 1

| 7 — ตรวจรับ | ภาพ 375/1440 ทุกหน้า, contrast และคีย์บอร์ด, ความเร็วหน้าแรก, lint/test/build ผ่าน | ✔ |

## กติกาที่ไม่เปลี่ยน (จาก PRODUCT.md)

- ภาพถ่ายต้องเป็นสถานที่นั้นจริงและมีเครดิต ไม่ใช้ภาพที่สร้างด้วย AI ของสถานที่จริง
- ไม่มีตัวเลขแต่งขึ้น: ไม่มีคะแนนรีวิว จำนวนผู้ใช้ หรือรีวิวปลอม
- ไทยเป็นภาษาหลัก ไม่ตั้ง letter-spacing บนไทย
- ใช้ได้ด้วยนิ้วเดียวบนมือถือ ปุ่มกดอย่างน้อย 44px และอ่านได้ชัดบนจอโปรเจกเตอร์
- ไม่ push ไม่ deploy จนกว่าจะสั่ง

## Phase 2 อยู่ที่ไหน

- **Token:** `chiangmai-app/src/app/brand.css` (import จาก `globals.css`) ชื่อใหม่ทั้งหมด ไม่ซ้ำกับ token เดิม หน้าเก่าจึงหน้าตาเหมือนเดิมจนกว่าจะย้ายมาทีละหน้า token เดิมลบทิ้งใน Phase 7
- **ฟอนต์:** Prompt (400/500/600) และ Allura โหลดใน `src/app/[locale]/layout.tsx` ฟอนต์เดิมสามตัวยังอยู่จนหน้าสุดท้ายย้ายเสร็จ
- **Component:** `chiangmai-app/src/components/brand/` — ปุ่ม, ปุ่มไอคอน, ชิป, ช่องค้นหา, ป้าย, หัวข้อ, กล่อง, ทิป, โลโก้, ภาพสถานที่ / ไม่มีภาพ / เครดิต, การ์ดสถานที่, การ์ดหมวดหมู่
- **ข้อความ:** ส่วน `ui` ใหม่ใน `src/i18n/dictionaries/th.ts` และ `en.ts`
- **หน้าตรวจ:** http://localhost:3100/th/design (มีเฉพาะตอนพัฒนา ไม่ถูก index) แสดงทุก component ด้วยข้อมูลจริง สลับธีมมืดได้

## Phase 3 อยู่ที่ไหน

- **Header + เมนูมือถือ:** `chiangmai-app/src/components/brand/site-header.tsx` — โลโก้, หน้าแรก / สำรวจ ▾ (หมวดพร้อมจำนวนจริง) / คู่มือ, ปุ่มค้นหา, ปุ่ม "วางแผนทริป", และเมนูบัญชีที่รวมภาษา ธีม และการเข้าสู่ระบบ ต่ำกว่า 1024px ทั้งหมดย้ายเข้า sheet ด้านขวา (`<dialog>` ของเบราว์เซอร์ใน `dialog.tsx`)
- **Footer:** `site-footer.tsx` บนแถบสีป่า พร้อมเครดิตข้อมูลสภาพอากาศและแผนที่
- **หน้าแรก:** `src/app/[locale]/page.tsx` + `src/components/home/` หกส่วนตามต้นแบบ ตัวเลขทริปตัวอย่างมาจาก `buildSchedule` และ `dayStats` ของตัววางแผนเอง (วันเดียวกับปุ่ม "เริ่มจากทริปตัวอย่าง" ในตัววางแผน)
- **ข้อความ:** ส่วน `shell` และ `homepage` ใน `th.ts` / `en.ts` (`home` เดิมยังใช้กับ metadata)
- **กฎโฟกัสเก่า:** `:focus-visible` ใน `globals.css` ไม่บังคับใช้ในพื้นที่ที่มี `data-brand` แล้ว (header, footer, dialog, หน้าแรก, หน้าตรวจ) เพราะ `!important` ของมันทำให้ปุ่มแคปซูลกลายเป็นมุมเหลี่ยม
- หน้าเก่าที่ยังไม่ย้ายใช้ header/footer ใหม่แล้ว ส่วนเนื้อหายังเป็นของเดิมจนถึง Phase ของตัวเอง

## Phase 4 อยู่ที่ไหน

- **หน้าสำรวจ:** `chiangmai-app/src/app/[locale]/explore/explore-client.tsx` เขียนใหม่ทั้งหมด ค้นหาด้วย `?q=` (ทุกคำต้องตรง ค้นทั้งชื่อไทย/อังกฤษ คำอธิบาย แท็ก ย่าน หมวด) หมวดพร้อมจำนวน แผงตัวกรอง (ตำแหน่งในเมือง งบ ช่วงเวลา ระยะ อำเภอ) ใกล้ฉัน/จุดที่เลือก/ย่าน พร้อมรัศมี เทียบหลายที่บนแผนที่ โหมดเพิ่มจากตัววางแผน (`?from=planner&day=N`) และบนมือถือสลับรายการ/แผนที่ด้วย `?view=map` ตรรกะการกรองอยู่ใน `src/lib/explore/filter.ts` (มีเทสต์)
- **ลำดับ "แนะนำ":** เมื่อไม่ได้เลือกหมวด จะสลับหมวดกันไปทีละที่ (`mixCategories` ใน `sort.ts`) ไม่ให้เปิดมาเจอวัด 24 แห่งติดกัน ตัวเลือกเรียงตามคะแนนถูกเอาออก เพราะคะแนนในข้อมูลเป็นตัวเลขที่เราใส่เอง ไม่ใช่รีวิวของใคร
- **หน้าสถานที่:** `src/app/[locale]/place/[slug]/page.tsx` ตามต้นแบบ ข้อมูลเดิมครบ (เรื่องราว ทริค เมนูเด่น รางวัลพร้อมแหล่งอ้างอิง เรื่องที่ควรรู้) และ "ก่อนไป" ที่สร้างจากข้อมูลจริงเท่านั้น (การแต่งกาย ถอดรองเท้า การจอง แสงทอง ความสูง) JSON-LD ไม่มี `aggregateRating` แล้วด้วยเหตุผลเดียวกัน ชิ้นส่วนฝั่ง client อยู่ใน `src/components/place/` (ปุ่มแชร์/เส้นทาง/แถบปุ่มมือถือ อากาศ ฝุ่นควันตามฤดู) และ `components/map/compare-map.tsx`
- **แผนที่สไตล์บอร์ด:** `src/lib/map/board-theme.ts` เปลี่ยนสีแผนที่ MapTiler เป็นโทนบอร์ดทั้งโหมดสว่าง/มืด วาดคูเมือง และตั้งชื่อปุ่มแผนที่เป็นภาษาของหน้า ใช้ทั้ง `explore-map.tsx` และ `place-map.tsx`
- **ชิ้นส่วนใหม่ที่ใช้ร่วมกัน:** `PlanToggle`, `FavoriteToggle`, `SignInPrompt`, `Select`, `aqi.tsx` และ `PlaceCard` แบบ `layout="auto"` ใน `src/components/brand/` toast ปรับเป็นสีป่า
- **ไฟล์เก่าที่ไม่มีใครใช้แล้ว (ลบใน Phase 7):** `components/place-location-card.tsx`, `place-sticky-actions.tsx`, `weather/place-weather-panel.tsx`, `weather/weather-error-boundary.tsx`, `explore/zone-filter.tsx`, `explore/explore-results-bar.tsx` ส่วน `components/place-card.tsx` และ `lib/map/theme.ts` ยังใช้อยู่ในหน้าที่ยังไม่ย้าย

## Phase 5 อยู่ที่ไหน

- **ตัววางแผน:** `chiangmai-app/src/app/[locale]/planner/page.tsx` เรียก `PlannerWorkspace` ใน `src/components/plan/planner-workspace.tsx` ชิ้นส่วนทั้งหมดอยู่ใน `src/components/plan/` (หัวทริป, แท็บวัน, รายการจุดแวะ, ถาดที่ยังไม่จัดวัน, ตรวจวันนี้, ภาพรวมทั้งทริป, เก็บแผน, แถบล่างมือถือ, ตัวเลือกสถานที่, AI, พิมพ์, แผนที่) ตัวคำนวณเวลา เส้นทาง งบ อากาศ และเทศกาลเป็นของเดิมทุกตัว ไม่ได้แก้
- **ลากย้าย:** ลากในวัน ลากข้ามวันโดยวางบนแท็บวัน (แท็บติดด้านบนตอนเลื่อน) ลากจากถาดลงวัน และใช้คีย์บอร์ดได้ (Space, ลูกศร, Space) นอกจากลากยังมีเมนู "ย้ายไปวัน…" ทุกการย้าย/ลบมีปุ่มเลิกทำ การย้ายใช้ `moveFromTo` ใน `restore.ts` ที่ระบุวันต้นทาง สถานที่ที่ซ้ำสองวันจึงย้ายถูกตัว
- **ลิงก์ที่ยังใช้ได้:** `?plan=` (นำเข้าแผนที่แชร์), `?add=day-N` (เปิดตัวเลือกสถานที่ ปุ่มย้อนกลับปิด), `?highlight=` และ `?trip=` (เปิดทริปที่บันทึกไว้) ตัวฟัง URL สามตัวยังเป็นไฟล์เดิมใน `components/planner/`
- **หน้าแชร์ทริป:** `src/app/[locale]/trip/[token]/page.tsx` แสดงทริปแบบอ่านอย่างเดียว เวลาเป็นตามที่เจ้าของบันทึก (ไม่คำนวณใหม่) แต่ละวันมีปุ่มเปิดเส้นทางใน Google Maps สถานที่ที่หลุดจากรายการยังแสดงพร้อมบอกว่าไม่อยู่แล้ว ปุ่มบันทึกสำเนา (`components/trips/copy-shared-trip-button.tsx`) ใช้ `SignInPrompt` เมื่อยังไม่เข้าสู่ระบบ ไม่ถูก index เหมือนเดิม
- **ไฟล์เก่าที่ไม่มีใครใช้แล้ว (ลบใน Phase 7):** ทุกไฟล์ใน `components/planner/` ยกเว้น `plan-import-listener.tsx`, `place-picker-url-sync.tsx`, `planner-highlight-sync.tsx` (ตัววางแผนใหม่ใช้) — ส่วน `planner-map.tsx`, `planner-map-loader.tsx`, `open-in-maps-link.tsx` หน้ารายการโปรดเลิกใช้แล้วใน Phase 6 ดูด้านล่าง

## Phase 6 อยู่ที่ไหน

- **คู่มือ:** หน้ารวม `chiangmai-app/src/app/[locale]/guides/page.tsx` และหน้าอ่าน `guides/[slug]/page.tsx` เป็น server component ทั้งคู่ ภาพปกมาจาก `src/components/guides/guide-cover.tsx` ซึ่งใช้ภาพถ่ายสถานที่ที่มีเครดิต (ทริปวัด = วัดเจดีย์หลวง) หรือภาพวาดพร้อมไอคอนเมื่อไม่มีภาพถ่าย ไม่ใช้ `/images/guides/*.jpg` ในหน้าแล้ว เพราะยังไม่รู้ที่มาของภาพ (แต่ `guides/[slug]/opengraph-image.tsx` ยังใช้อยู่ รอเจ้าของยืนยัน) ในเนื้อเรื่อง ชื่อสถานที่ครั้งแรกเป็นลิงก์ และมีการ์ดสถานที่พร้อมปุ่มหัวใจ/เพิ่มลงแผนอยู่ข้างๆ
- **เกี่ยวกับเรา (หน้าใหม่):** `src/app/[locale]/about/page.tsx` อยู่ในเมนูบน เมนูมือถือ และ footer แล้ว ตัวเลขในหน้า (จำนวนสถานที่ ภาพถ่าย หมวด) นับจากข้อมูลจริงตอน build ส่วน "ใครทำ" ยังรอชื่อจากเจ้าของ จึงแสดงแค่ชื่อมหาวิทยาลัย
- **ทริปของฉัน:** `src/components/trips/my-trips-list.tsx` การ์ดใหม่ ปุ่มเปลี่ยนชื่อ/ทำสำเนา/แชร์/ลบ เป็นปุ่มไอคอน 44px ที่บอกชื่อทริปให้โปรแกรมอ่านหน้าจอ กล่องโต้ตอบสามตัว (`rename-dialog`, `share-dialog`, `confirm-dialog`) ใช้ `Dialog` ของแบรนด์ ปุ่มลบไม่ใช้สีแดง (แบรนด์ไม่มีสีแดง) ใช้ไอคอนถังขยะกับคำแทน และโฟกัสเริ่มที่ปุ่ม "เก็บไว้"
- **รายการโปรด:** `src/components/favorites/favorites-gallery.tsx` ชิปกรองตามหมวดพร้อมจำนวน การ์ดแบบเดียวกับหน้าสำรวจ แผนที่เปลี่ยนเป็นแผนที่ของหน้าสำรวจ จึงแสดงแค่หมุด ไม่ลากเส้นเชื่อมระหว่างสถานที่ (รายการโปรดไม่ใช่เส้นทาง) "เพิ่มทั้งหมดลงแผน" ทำงานเหมือนเดิม
- **บัญชี:** `src/app/[locale]/account/page.tsx` และ `src/components/account/account-actions.tsx` ตารางข้อมูลที่เก็บ ดาวน์โหลด JSON และลบบัญชี (ต้องพิมพ์ DELETE ก่อน ปุ่มจึงกดได้) การทำงานเดิมทุกอย่าง
