## 4. Redesign brief

### Mode

**Redesign · Overhaul** — แทนที่ภาษาภาพ layout component และ composition ของทุกหน้า คงความจริงของโปรดักต์ เนื้อหา ฟังก์ชัน และ route ไว้ทั้งหมด ของเดิมเป็นหลักฐานว่าโปรดักต์คืออะไร ไม่ใช่กรอบของสิ่งที่จะเป็น

โหมดรายหน้า: หน้าแรก = Persuade · explore, planner, login, my-trips, favorites, account = Operate · หน้าสถานที่, คู่มือ (รายการ + บทความ), trip/[token], credits/privacy/terms = Read

### Preserve — เก็บไว้

**ความคิดที่เป็นของเว็บนี้จริง (ยกระดับ ไม่ทิ้ง)**
- **เมืองสี่เหลี่ยม** — ผังกำแพงเมืองที่วางสถานที่ 204 แห่งจากพิกัดจริง ใช้ทั้งเป็นโลโก้ ตัวกรองโซน และตัวบอกตำแหน่งในหน้าสถานที่ เป็นสิ่งเดียวในเว็บตอนนี้ที่เว็บอื่นลอกไปใช้ไม่ได้ ควรเป็นกระดูกสันหลังของระบบใหม่ (กริด แผนที่ การนำทาง) ไม่ใช่วิดเจ็ตประกอบ
- **น้ำเสียงของ copy ไทย** — "เชียงใหม่ใจดีกับคนที่ไม่รีบ", "ที่ที่เรากลับไปเอง", "เมืองนี้เป็นสี่เหลี่ยม" เขียนเป็นไทยจริง ไม่ใช่แปล เก็บทุกประโยค
- **ความซื่อตรงของข้อมูล** — ป้าย "โดยประมาณ", หมายเหตุว่าผังนอกกำแพงถูกบีบระยะ, เครดิตภาพรายรูป, รูปที่ต้องพิสูจน์ได้ว่าเป็นสถานที่นั้นจริง

**เนื้อหา** — ทุกชิ้นยังเข้าถึงได้: 204 สถานที่ (คำบรรยาย ทริค เวลาเปิด ราคา ระยะเวลา), 3 คู่มือ, ข้อความ UI ใน `th.ts` / `en.ts`, อากาศและ AQI, เทศกาล, แบนเนอร์หมอกควันตามฤดู

**ฟังก์ชัน** — ทุกอย่างของ planner (วันที่/คน/งบ, ลากเรียง, ถาดยังไม่จัดวัน, ทริปตัวอย่าง, AI, ตรวจแผน/สรุป/ไทม์ไลน์แสงทอง, เปรียบเทียบพาหนะ, บันทึก, แชร์ลิงก์/QR, พิมพ์), ตัวกรองทั้งหมดของ explore, มุมมองแผนที่, ใกล้ฉัน, เทียบสถานที่, รายการโปรด, บัญชีและการส่งออก/ลบข้อมูล

**งานวิศวกรรมที่ทำไว้ดีแล้ว** — focus ring ที่ปิดไม่ได้, skip link, h1 ครบทุกหน้า, ระบบ token สองธีมที่วัด contrast มาแล้ว, `Section`/`Container` primitive, map proxy, theme-init script กันจอกระพริบ, ไอคอนชุดเดียว (lucide)

### Highest-risk change

**Planner** — เป็นหน้าที่ซับซ้อนที่สุด (29 component, dnd-kit, แผนที่, store ที่ persist, sync กับ cloud) เป็นจุดขายตอนนำเสนอ และเป็นหน้าที่ต้องย้ายโครงมากที่สุด ความเสี่ยงคือพฤติกรรมพังเงียบๆ ขณะย้าย layout: ลำดับ drag, การ fit แผนที่, id ที่ stepper ใช้ scroll (`planner-details`, `planner-days`, `planner-toolbar`), การ sync แผนที่บันทึกไว้

วิธีคุม: ไม่แตะ store และ `lib/planner/**`; ย้ายทีละ component โดยคง props เดิม; รัน `npm test` ทุก commit; ตรวจด้วยเบราว์เซอร์ทุกรอบ: โหลดทริปตัวอย่าง → ลากสลับ → ย้ายข้ามวัน → ลากด้วยคีย์บอร์ด → บันทึก → เปิดลิงก์แชร์ → พิมพ์

ความเสี่ยงรองลงมา: (1) เปลี่ยนฟอนต์กระทบ LCP และ layout ของทุกหน้า (2) เอา `Reveal` ออกจาก 17 ไฟล์พร้อมกัน (3) ภาพ hero ใหม่กลายเป็น LCP element ต้องไม่ช้ากว่าเดิม
